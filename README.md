# Vocabulary Wallpaper — Phase 1

This is the Phase 1 source bundle for the Android Studio project.

## Project configuration
- Package / namespace: `com.example.vocabularywallpaper`
- Android Gradle Plugin: `8.11.1`
- Gradle wrapper distribution: `8.13`
- Kotlin: `2.4.21`
- Compose BOM: `2026.09.00`
- Activity Compose: `1.13.0`
- compileSdk / targetSdk: `36`
- minSdk: `26`
- JVM target: `17`

## Open in Android Studio
1. Create a new project using the **Empty Activity** template (Jetpack Compose, not Empty Views Activity).
2. Use the project name `VocabularyWallpaper` and package `com.example.vocabularywallpaper`.
3. Set Minimum SDK to API 26.
4. Keep the Gradle wrapper scripts and wrapper JAR generated by Android Studio.
5. Copy/replace the files from this bundle into the matching locations in the new project.
6. Sync Gradle, then run the `app` configuration on an emulator or Android phone.

The archive includes the wrapper properties file, but intentionally relies on Android Studio's generated `gradlew`, `gradlew.bat`, and `gradle-wrapper.jar`. Do not delete those generated wrapper files.

## Phase 1 scope
The app opens into a Material 3 dashboard with a sample word-card preview. The word, interval, and background shown are static UI sample data. The wallpaper service, image picker, JSON repository, settings storage, and timed word rotation are not implemented yet; they belong to later phases.
